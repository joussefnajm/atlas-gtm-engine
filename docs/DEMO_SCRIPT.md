# Demo script (2 to 3 minutes)

1. **Intake (0:00).** "A real company, Force Energy, describes what it sells in plain language." Show the intake text and press *Run pipeline*. Point at the *Agent thinking* panel filling in.
2. **ICP (0:25).** Fields with confidence bars and the reason for each. Accept one adjacent segment; mention it is logged.
3. **Leads (0:50).** Table with tier, score, and a clickable public source on every row. "No source, no lead."
4. **Graph (1:15).** Run *Competitor displacement* and *Strong buying signals*. Run *Warm introduction paths*: empty. Add a known contact, run it again: a path appears.
5. **Approvals (1:50).** A Spanish draft with the cited signal. Show *facts ok, security ok*. Approve, edit one, reject one. Press *Send queue to WhatsApp agent* and show the numbered list the founder answers from WhatsApp. Import decisions.
6. **Pipeline and usage (2:25).** Dispatch (dry run), simulate a reply (sandbox label), show the Kanban with AI versus rep attribution. Open *Agents and usage*: credits, metering events, run the reviewer self-test (8 of 8).
7. **Close (2:50).** "New today: the engine. Already running in the company: the agents, the platform and the approval habit. Any company can be added as a workspace."
